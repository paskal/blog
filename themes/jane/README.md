# Hugo Theme Jane (Minimal Fork)

This is a minimal fork of [hugo-theme-jane](https://github.com/xianmin/hugo-theme-jane) by [xianmin](https://xianmin.org).

## Changes from original

This fork has been stripped down to only include features needed for [terrty.net](https://terrty.net):

- Removed Google Analytics, Baidu/Google verification meta tags
- Removed Chinese services (Baidu/Tencent analytics, busuanzi/leancloud counters)
- Removed all comment systems except Remark42 (Disqus, Valine, Changyan, LiveRe)
- Removed Google Search integration
- Removed debug mode (Eruda console)
- Removed unused options (logoTitle, wallpaper, homeFullContent, paginateOriginalStyle, showMenuLanguageChooser)
- Removed Chinese video/music shortcodes (Youku, music)
- Kept only English and Russian i18n translations
