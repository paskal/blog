# Hugo Theme Jane (Minimal Fork)

This is a minimal fork of [hugo-theme-jane](https://github.com/xianmin/hugo-theme-jane) by [xianmin](https://xianmin.org).

## Changes from original

This fork has been stripped down to only include features needed for [terrty.net](https://terrty.net):

- Removed Chinese services support (Baidu analytics, Tencent analytics, busuanzi counter, leancloud counter)
- Removed Chinese comment systems (Valine, Changyan, LiveRe)
- Removed Chinese video/music shortcodes (Youku, music)
- Kept only English and Russian i18n translations
- Simplified scripts and templates
